Other blockers and next step
The classical detector needs a genuine same-setup empty baseline, aligned
1400x520 images. This dataset supplies no paired empty baseline/calibration.
No baseline, calibration, QR or ArUco markers were fabricated.
Current registration requires ArUco IDs 0..3 (not QR codes).
Next concrete marker-free classical test: acquire an overhead empty-board and
populated image without moving camera/board, plus at least three empty frames.
In a separate evaluation utility, manually select the same physical reference
holes/corners, establish a shared 1400x520 warp, and save the genuine empty median.
Then invoke ClassicalBreadboardDetector directly, bypassing marker-dependent
registration only in that evaluation. This has not been implemented here.
Alternatively supply the trained compatible pose checkpoint to run direct
image-space detection without marker registration or an empty baseline.
Without training provenance, any subsequent dataset evaluation is a smoke test,
not generalization evidence. No LED or electrical correctness claims.
